# FastBrainAge

FastBrainAge is the reusable Docker distribution of the retrained FastSPM
brain-age workflow developed in this repository. It is a separate artifact:
the historical `brainageR/` and `More/` implementations are not modified or
required by it.

The package follows the same central BrainAgeR idea—learn the relationship
between a standardized grey-matter image representation and chronological
age—but its current packaged artifact is **Exp2**, trained from the expanded
3,857-row cohort. The end-to-end acquisition and experiment workflow lives in
`pipeline/run_exp2_pipeline.py`.

The shortest complete core run is `python pipeline/run_exp2_pipeline.py
run-core`; add `--retrain` to rebuild the Exp2 head. CSF and
cortical-thickness analyses are explicit branches from the same data root.

## Workflow

```text
T1 NIfTI
  -> SPM12 Unified Segmentation (bias correction + MNI normalization)
  -> modulated normalized grey-matter map (mwc1)
  -> 4 mm FWHM smoothing and 4 mm resampling
  -> fixed 4 mm brain mask
  -> within-subject voxel z-normalization
  -> StandardScaler
  -> randomized PCA (128 components)
  -> Matern+White Gaussian Process Regressor (Exp2)
  -> chronological-age prediction and brain-age gap
```

The packaged model is trained from scratch for FastSPM maps. It is therefore
not input-compatible with the original CAT12-trained serialized BrainAgeR
model. A CAT12 map cannot be passed to this model and called equivalent.

For strict reproduction of the released model, provide FastSPM `mwc1` maps
generated with the same SPM12 recipe/runtime used for training. The Exp2 maps
were generated with SPM12 r7771's standalone MATLAB Runtime; the Docker
raw-image command uses the Octave-compatible SPM12 r7771 build. They are the
same algorithmic recipe, but numerical differences between MATLAB Runtime and
Octave can change individual voxels slightly. If new raw T1 images are
processed with this Docker image, process the entire training and application
cohort with this same image and retrain the model.

## Build

From this directory:

```bash
docker build -t fastbrainage:exp2 .
```

The image includes Octave-compatible SPM12 r7771 for raw T1 preprocessing.
No MATLAB license is required. The build is intentionally larger than a
prediction-only Python image because it includes the preprocessing runtime.

## Run

All input and output data should be mounted explicitly. The container does not
copy data into the repository or depend on a host-specific mount path.

Preprocess one raw T1 image:

```bash
docker run --rm \
  -v "$PWD/input:/data/in:ro" \
  -v "$PWD/output:/data/out" \
  fastbrainage:exp2 preprocess \
  /data/in/sub-0001_T1w.nii.gz /data/out/sub-0001_mwc1.nii
```

For a batch, place maps in the standard layout:

```text
maps/
  sub-0001/sub-0001_mwc1.nii
  sub-0002/sub-0002_mwc1.nii
```

Create a tab-separated manifest with at least `participant_id`; training
manifests also need `age`:

```text
participant_id  age
0001            42
0002            67
```

Extract features:

```bash
docker run --rm \
  -v "$PWD:/data" \
  fastbrainage:exp2 extract-features \
  --manifest /data/train.tsv \
  --maps-dir /data/maps \
  --output /data/train_features.npz
```

Train and serialize a model:

```bash
docker run --rm \
  -v "$PWD:/data" \
  fastbrainage:exp2 train \
  --manifest /data/train.tsv \
  --features /data/train_features.npz \
  --output-model /data/fastbrainage.joblib
```

Predict:

```bash
docker run --rm \
  -v "$PWD:/data" \
  fastbrainage:exp2 predict \
  --model /data/fastbrainage.joblib \
  --features /data/test_features.npz \
  --manifest /data/test.tsv \
  --output /data/predictions.tsv
```

Existing FastSPM `mwc1` maps can skip the preprocessing step. The
`participant_id` order in the manifest is used to reorder the feature archive,
so feature rows cannot silently become associated with the wrong subject.

The released model's direct feature/archive path is the reproducible path. See
`docs/COMPATIBILITY.md` before mixing maps generated by different SPM engines.

## Reproduce the expanded dataset and core experiment

The checked-in manifest is `pipeline/data/exp2_manifest.tsv`. It contains
3,857 de-identified rows, source URLs, access/licence reminders, ages, and
split assignments. It contains no MRI files. Each source's current access
terms still apply, and an external URL may change or disappear.

From the repository root:

```bash
python -m pip install -e .
docker build -t fastbrainage:exp2 .
python pipeline/run_exp2_pipeline.py validate
python pipeline/run_exp2_pipeline.py run-core --workers 1 --download-workers 8
```

`run-core` performs the ordered path from manifest preparation through raw-T1
download, FastSPM preprocessing, GM feature extraction, Exp2 prediction,
calibration-only bias correction, and corrected/uncorrected scoring. It writes
generated files under `pipeline/data/exp2/`; set `--data-root` to external
storage when needed. Use `--retrain` to rebuild the Exp2 head from the 2,742
training rows. Use `--skip-download`, `--skip-preprocess`, or `--skip-extract`
only when the corresponding outputs already exist under the same data root.

The complete run may download and process up to 3,857 T1 images. The Docker
image includes an Octave-compatible SPM12 r7771 build and does not require a
MATLAB licence. The released maps were generated with SPM12 r7771's
standalone MATLAB Runtime, so a clone can reproduce the recipe but may see
small numerical differences. For exact released predictions, use the
released model with compatible maps; for a fully regenerated cohort, process
all subjects with one runtime and retrain consistently.

The split boundaries are enforced by the pipeline: `train` fits only training
rows, `fit-bias` fits only calibration rows, and locked-test ages are read
only by the explicit final `score` step. The bias correction uses known
chronological age and is therefore an evaluation-time correction, not a
deployment operation for an unknown-age subject.

To run individual core stages instead:

```bash
python pipeline/run_exp2_pipeline.py prepare
python pipeline/run_exp2_pipeline.py download --workers 8
python pipeline/run_exp2_pipeline.py preprocess --image fastbrainage:exp2
python pipeline/run_exp2_pipeline.py extract-gm
python pipeline/run_exp2_pipeline.py train
python pipeline/run_exp2_pipeline.py predict
python pipeline/run_exp2_pipeline.py fit-bias
python pipeline/run_exp2_pipeline.py score
```

## CSF and ventricle experiment

CSF is a separate output of the same Unified Segmentation pass. The CSF
recipe writes modulated normalized CSF (`mwc3`) maps while the main recipe
writes GM (`mwc1`) maps. Run the branch through the same data root:

```bash
python pipeline/run_exp2_pipeline.py csf-preprocess --image fastbrainage:exp2
python pipeline/run_exp2_pipeline.py csf-features
python pipeline/run_exp2_pipeline.py csf-feature-age
python pipeline/run_exp2_pipeline.py csf-screen
python pipeline/run_exp2_pipeline.py csf-fusion
```

The branch uses the same Exp2 IDs and splits. Its primary question is whether
CSF/ventricle features contain age signal, not whether a small
calibration-only fusion should replace the frozen production model. The
completed audit found train correlations of total CSF Pearson/Spearman
`+0.677/+0.697` and total ventricle `+0.507/+0.514`; GM-normalized versions
were stronger. The simple fusion was not promoted.

CSF feature extraction requires `nilearn` and an accessible Harvard-Oxford
atlas. Set `HARVARD_OXFORD_ATLAS` to the atlas file before running
`csf-features`. CSF preprocessing reuses raw files created by the main
`download` stage when available, so it does not intentionally create a second
raw dataset.

## Cortical-thickness experiment

Cortical thickness is an exploratory branch, not a hidden addition to the
production feature vector. It consumes a label-free acquisition manifest and
keeps ages and predictions out of the pilot. The default calibration pilot is:

```bash
python pipeline/run_exp2_pipeline.py cortical --methods cortexode
```

`dldirect` and `cortexmorph` can also be requested, but require their external
repositories and checkpoints. The locked-test acquisition manifest may be
selected with `--include-locked-test` only for predeclared, label-blind
feature extraction. Score a candidate once, after selection, with the
dedicated evaluation script.

The completed CortexODE calibration run found age-related thickness signal,
but adding the global thickness summary changed MAE from `4.788` to `4.799`
years in the evaluated comparison. No cortical-thickness head was promoted.
The cortical branch reuses the main pipeline's downloaded raw file when a
prepared stage manifest is supplied.
