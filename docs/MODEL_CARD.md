# FastBrainAge model card

## Intended use

Research-only chronological brain-age experiments using structural T1 MRI
that has been processed into the FastSPM `mwc1` representation. The model is
intended to support reproducible method development and cohort-level audits.

## Not intended for

Clinical diagnosis, individual medical decisions, deployment across an
unseen scanner/site without validation, or interpreting the prediction as a
biological truth. A brain-age gap is a model residual, not a direct measurement
of ageing.

## Released training artifact

The included `models/exp2.joblib` artifact is trained on 2,742 rows from the
expanded Exp2 ledger. It uses within-subject-z features, StandardScaler,
PCA-128, and a Matern+White GPR, with a continuous age expansion factor of
1.010 around the training-age mean. The complete ledger has separate 554-row
calibration and 561-row locked-test splits; see the root `pipeline/` directory.
The released maps were generated by SPM12 r7771's standalone MATLAB Runtime;
the Docker image also provides an Octave-compatible SPM12 r7771 path for
consistent future preprocessing and retraining.

## Current confirmation result

The production evaluation protocol is the Exp2 train/calibration/locked-test
split. The locked-test labels are reserved for the explicit final evaluation
and are never used for fitting, bias correction, or experiment selection.
Earlier RBF artifacts and their confirmation results are historical release
material, not the current Exp2 result, and are omitted from this checkout.

## Known limitations

The model has not been proven scanner-independent, site-independent, or
uniformly accurate across the lifespan. Preprocessing changes the learned
image distribution, so this model must not be used with CAT12 maps unless a
new compatibility study and retraining establish that use case.
